# 🎃 할로윈 게임 파티

추억의 플래시 게임을 할로윈 버전으로 바꾼 교실용 웹 게임 모음입니다.
**혼자 하기(싱글플레이)** 와 **함께 하기(멀티플레이)** 로 나뉘어 있어요.

| 구분 | 게임 | 원작 | 한 줄 소개 |
| --- | --- | --- | --- |
| 혼자 하기 | **호박분투** | 고군분투 (한게임 플래시) | 호박군이 지붕 위를 달리며 점프하고, 거미줄 그네로 날아 할로윈 파티장까지 가요 |
| 혼자 하기 | **죽림고스트** | 죽림고수 (한게임 플래시) | 꼬마 유령이 대나무숲에서 사방으로 날아오는 화살을 피하며 오래 버텨요 |
| 함께 하기 | **동암초 탈출** | 화이트데이 (느낌만) | 3D로 만든 우리 학교에서 경비 아저씨를 피해 몰래 다니며, 모둠이 함께 수수께끼를 풀고 탈출해요 |

설치할 것은 없습니다. 브라우저(크롬, 웨일, 엣지, 사파리)만 있으면 컴퓨터·크롬북·태블릿·휴대폰에서 모두 돌아가요.

> 🔗 GitHub Pages를 켜면 주소는 **https://bpsbps123456-beep.github.io/halloween/** 예요. 켜는 방법은 아래에 있어요.

## 아이들과 함께 하는 방법

### 1) 인터넷 주소 만들기 (GitHub Pages, 한 번만 하면 돼요)

1. [저장소 설정의 Pages 화면](https://github.com/bpsbps123456-beep/halloween/settings/pages)을 엽니다.
2. **Build and deployment → Source** 를 `Deploy from a branch` 로 두고,
   **Branch** 는 `claude/peaceful-gauss-tlud71`, 폴더는 `/ (root)` 를 골라 **Save** 를 누릅니다.
3. 1~2분 뒤 같은 화면 위쪽에 주소가 나와요: **https://bpsbps123456-beep.github.io/halloween/**
4. 이후 이 브랜치에 올라오는 수정은 자동으로 반영돼요.

### 2) 학생들에게 나눠 주기

- 교실 TV·전자칠판에 첫 화면을 띄우고 **📱 학생 기기로 열기** 를 누르면 큰 QR 코드와 주소가 나와요.
  학생은 태블릿 카메라로 찍기만 하면 돼요. (이 버튼은 인터넷 주소로 열었을 때만 보여요)
- 한 대의 컴퓨터를 돌아가며 해도 좋아요. 명예의 전당이 그 컴퓨터에 쌓여서 반 전체 순위 대결이 돼요.
- 기록(명예의 전당)은 기기마다 따로 저장돼요. 각자 태블릿으로 하면 각자의 순위가 남아요.

### 3) 인터넷 주소 없이 열기

- **Code → Download ZIP** 으로 내려받아 압축을 풀고 `index.html` 을 두 번 누르면 바로 돼요.
  (인터넷이 없으면 글꼴만 기본 글꼴로 바뀌어요)
- 선생님 컴퓨터에서 `python3 -m http.server 8000` 을 실행하면 같은 와이파이의 학생 기기에서
  `http://선생님컴퓨터IP:8000` 으로 들어올 수 있어요.

## 🎃 호박분투 (원작: 고군분투)

호박군은 저절로 달려요. 지붕 사이 틈을 건너며 사탕을 모아 **파티장 문**까지 가면 단계 성공!

| 조작 | 하는 일 |
| --- | --- |
| `Space` · `↑` · 클릭 · 화면 터치 | 점프 |
| 공중에서 한 번 더 누르기 | 앞쪽 위의 **호박 등불**에 거미줄을 걸어요 (닿는 등불은 민트색 원으로 반짝여요) |
| 누르고 있기 → 떼기 | 그네처럼 매달렸다가, 떼는 순간 휘익 날아가요 |
| 오래 매달리기 | 저절로 **공중제비**를 돌며 놓아요. 그때 다음 등불에 거미줄을 또 걸 수 있어요 |
| `P` / `Esc` | 잠깐 멈추기 |
| `M` | 소리 끄기·켜기 |

- **점수**: 사탕 5점 · 황금 별사탕 30점(2단계 60점, … 6단계 180점) · 한 단계의 황금 별사탕을 **모두** 모으면 +200점 · 단계 성공 +100점
- **목숨**: 단계마다 호박 3개. 떨어지면 하나를 잃고 마지막으로 밟은 넓은 지붕에서 다시 달려요.
- **6단계, 난이도(10점 만점)는 2 → 4 → 6 → 8 → 9 → 10**

| 단계 | 이름 | 난이도 | 달리기 속도 | 새로 나오는 것 |
| --- | --- | --- | --- | --- |
| 1 | 호박 마을 | 2 | 324 | 점프와 거미줄 1개 |
| 2 | 박쥐 골목 | 4 | 368 | 등불 2개 잇기, 좁은 지붕 징검다리 |
| 3 | 마녀의 지붕 | 6 | 412 | 등불 2개 잇기가 더 자주, 높낮이 차이 커짐 |
| 4 | 유령 시계탑 | 8 | 456 | 등불 3개 잇기 |
| 5 | 해골 성벽 | 9 | 478 | 징검다리 3번, 이어 타기 많아짐 |
| 6 | 달빛 대저택 | 10 | 500 | 모든 것이 가장 빠르고 멀어요 |

  난이도가 오르면 빨라질 뿐 아니라 틈이 넓어지고, 지붕이 짧아지고, 거미줄을 놓는 때가 더 정확해야 해요.
  아이 손을 흉내 낸 자동 검사(타이밍을 조금씩 틀리게 누르는 플레이어)로 재 보면,
  목숨 3개로 단계를 끝내는 비율이 대략 100% → 83% → 75% → 35% → 25% → 13% 로 내려가요.
- 한 번 성공한 단계는 처음 화면의 **단계 골라 하기**로 바로 시작할 수 있어요.
- 🤫 **숨은 기능**: 처음 화면에서 키보드로 `b` `o` `o` 를 차례로 누르면 **1.5배속 유령 모드**가 켜져요. 원작에 10년 넘게 숨어 있던 2배속 모드를 따라 했어요. (명예의 전당에는 👻 표시가 붙어요)

## 👻 죽림고스트 (원작: 죽림고수)

사방에서 날아오는 화살을 피해 최대한 오래 버티세요. **버틴 시간이 점수**예요.

| 조작 | 하는 일 |
| --- | --- |
| `←` `↑` `↓` `→` · `W` `A` `S` `D` | 유령 움직이기 (대각선도 돼요) |
| 화면을 누른 채 끌기 (터치·마우스) | 손가락이 움직인 만큼 유령이 따라와요 |
| `P` / `Esc`, `M` | 잠깐 멈추기, 소리 끄기·켜기 |

- 원작처럼 **빛나는 화살촉 끝만 위험**해요. 화살대와 깃은 스쳐도 괜찮아요. 아슬아슬하게 피하면 "아슬!" 하고 세어 줘요.
- 난이도는 한 가지예요 (원작 죽림고수와 비슷한 빠르기). 화살이 들어올 자리는 화면 가장자리에 주황색 표시로 미리 알려 줘요.
- 시간이 지나면 레벨이 올라요 (10·20·35·50·70초): 한 발씩 → 여러 발 → 모여드는 화살·빨간 빠른 화살 → 구멍 뚫린 화살 벽 → 빙 둘러싸는 화살 → 끝없는 화살비.
- **칭호**: 아기 유령(10초 미만) → 꼬마 유령 → 날쌘 유령(20초) → 죽림 고수(30초) → 죽림 달인(45초) → 전설의 고스트(60초) → 할로윈의 신(90초 이상)

## 🏫 동암초 탈출 (함께 하기 · 3D 모둠 방탈출)

할로윈 밤, **6-3 교실**에서 깜빡 잠들었다 깨어 보니 학교 문이 모두 잠겼어요.
선생님이 주신 **신관·본관 대피 안내도**대로 만든 3D 학교를 1인칭으로 걸어 다니며,
방마다 수수께끼를 풀어 숫자를 모으고 **본관 1층 중앙 현관** 자물쇠를 열어 탈출해요.

- **모둠마다 기기 한 대** (태블릿·크롬북·컴퓨터). 한 명이 조종하고, 나머지는 함께 찾고 계산해요. 종이와 연필이 있으면 좋아요.
- 걸린 시간이 기록이에요. **힌트 한 번 +30초**, **경비원에게 잡히면 +30초**. 명예의 전당은 빠른 모둠 순서예요.
- 끝까지 30~40분쯤 걸려요. 중간에 창을 닫아도 **이어서 하기**로 그 방부터 다시 할 수 있어요 (3시간 안).

| 조작 | 컴퓨터 | 태블릿 |
| --- | --- | --- |
| 걷기 | `W` `A` `S` `D` · `↑` `↓` | 왼쪽 아래를 누르고 끌기 (조이스틱) |
| 뛰기 (발소리가 나요!) | `Shift` | 조이스틱을 끝까지 밀기 |
| 둘러보기 | 마우스로 끌기 · `←` `→` | 오른쪽 화면을 끌기 |
| 살펴보기 (물건 누르기) | 클릭 · `E` (가운데 점이 가리키는 것) | 물건을 짧게 누르기 |
| 숨기·나가기 (복도) | `E` · `Space` | 오른쪽 아래 **숨기** 버튼 |

### 탈출 경로와 수수께끼 (6학년 수준)

| 순서 | 장소 | 수수께끼 |
| --- | --- | --- |
| 1 | 신관 2층 6-3 교실 | **칠판의 수수께끼**: 교실 곳곳(책상 밑, 사물함 위, 창틀, 천장, 쓰레기통 …)에 숨은 호박·박쥐·거미를 세어 칠판의 식(예: (🎃+🦇)×🕷️)을 풀면 선생님 책상 서랍 비밀번호 |
| 2 | 신관 3층 과학실 | **마녀의 물약**: 칠판의 식으로 물약 양을 구해 부어요 (소수의 나눗셈·분수의 나눗셈·비와 비율, 예: 빨강 = 7.2 ÷ 0.06, 빨강에 대한 파랑의 비율 = 75%) |
| 3 | 본관 3층 도서관 | **속담 책장**: 책장 어딘가에서 보랏빛으로 빛나는 책 3권을 찾아, 초성만 보이는 속담 빈칸을 글자 카드로 채워요 |
| 4 | 본관 2층 방송실 | **유령의 모스 부호**: 삐- 소리와 ON AIR 불빛을 벽의 모스 부호표로 풀어 4자리 비밀번호를 찾아요 |
| 5 | 본관 2층 교무실 | **선생님 자리 찾기**: 화이트보드의 단서 4~6개로 선생님 다섯 분의 자리를 모두 알아내요 (논리 추론, 답은 꼭 하나) |
| 6 | 본관 1층 보건실 | **보건실 약장**: 보건실 곳곳의 처방전 쪽지 4장을 찾아 그림 식(곱셈·나눗셈·괄호)을 풀고 약장 비밀번호를 맞혀요 |
| 끝 | 본관 1층 중앙 현관 | 방마다 받은 숫자 6개를 자물쇠 그림 순서대로 맞추고, 모둠 모두가 화면을 두드려 무거운 문을 밀어요 |

수수께끼는 판마다 새로 만들어져요 (숨는 자리, 숫자, 비율, 속담, 단서가 매번 달라요). 방마다 힌트는 2번까지 (+30초씩).

### 복도의 경비 아저씨 (화이트데이처럼)

방과 방 사이 복도 5곳에서는 손전등을 든 경비 아저씨가 순찰해요. 뒤로 갈수록 빨라지고 예민해져요.

- **손전등 불빛**에 들어가면 “거기 누구냐!” 하고 쫓아와요. 빨리 숨을 곳에 숨으면 놓쳐요.
- **숨을 곳**: 청소함, 화장실, 열린 교실 문. 숨을 곳 앞에서 **숨기**를 누르면 청소함 틈으로 밖을 엿볼 수 있어요.
- **뛰면 발소리**가 나서 경비 아저씨가 돌아봐요. 가까이 있을 땐 살금살금 걸어요.
- 경비 아저씨가 **교실을 살피러 들어가면** (교실 창이 노랗게 빛나요) 지나갈 기회예요.
- 위쪽 작은 지도에 나·경비원·숨을 곳·도착 문이 보여요. 발소리는 들리는 방향(왼쪽·오른쪽)에서 나요.

### 선생님 설정 (우리 반만의 게임으로)

처음 화면의 **선생님 설정**에서 정할 수 있어요.

- 학교 이름, 출발 교실(우리 반)
- **담임 선생님 이름**: 칠판(“담임 ○○○ 선생님”), 선생님 책상 이름표, 교무실 자리 퍼즐에 나와요
- **급훈**: 칠판 위 액자에 걸려요
- **주번**, **떠든 사람**: 칠판에 적혀요 (떠든 사람은 正 표시와 함께, 유령 부가 놀려요)
- **사물함 이름표**: 반 친구 이름을 번호 순서대로 적으면 교실 뒤 사물함에 이름표가 붙어요
- 교무실 컴퓨터에 나올 **선생님 문제 3개**

저장하면 학생 기기용 주소와 QR 코드가 나와요 (인터넷 주소로 열었을 때). 그 주소로 연 기기에서만 이 설정이 나와요.
아이들 이름은 그 기기와 주소 안에만 담기고, 공개된 사이트 코드에는 들어가지 않아요.

### 선생님 정답지

수수께끼는 판마다 새로 만들어져서 정해진 비밀번호가 없어요.
게임 중에 화면 위쪽 **시계(⏱)를 빠르게 5번** 누르면, 그 기기에서 하는 판의 정답(서랍·물약·속담·모스 부호·자리·약장·현관 자물쇠)이 모두 나와요.

> ⚠️ 저장소와 사이트가 공개라서, 게임 속 학교 지도(층별 교실 배치)도 누구나 볼 수 있어요. 마음에 걸리면 `multi/escape/core.js` 맨 위의 `BUILDINGS` 를 바꾸면 돼요.

## 교실에서 쓰는 팁

- **명예의 전당**은 그 컴퓨터(브라우저)에 저장돼요. 한 컴퓨터를 돌아가며 쓰면 반 전체 순위가 쌓여요. 다른 컴퓨터와는 공유되지 않아요.
- TV나 전자칠판에 띄울 때는 게임 오른쪽 위 **⛶ 전체 화면** 버튼을 누르세요. 화면 크기에 맞춰 커져요.
- 휴대폰은 **가로로** 돌리면 더 크게 보여요.
- 처음에 소리가 안 나면 화면을 한 번 누르세요. 브라우저는 사용자가 한 번 누른 뒤에야 소리를 내요.

## 원작과 달라진 점

- **호박분투**: 원작의 와이어 → 거미줄, 은화·금화 → 사탕·황금 별사탕, 건물 → 할로윈 마을 지붕. 아이들을 위해 목숨 3개, 지붕 끝 여유, 착지 직전에 누른 점프도 받아 주는 장치를 넣었어요.
- **죽림고스트**: 고수 → 꼬마 유령, 화살촉에 불빛을 넣어 "촉만 위험" 규칙이 눈에 보이게 했어요. 화살이 들어올 자리를 화면 가장자리에 미리 표시해요.
- **동암초 탈출**: 화이트데이처럼 경비원을 피해 숨어 다니는 느낌만 빌려 왔어요. 무서운 장면은 없고, 잡혀도 복도 처음으로 돌아갈 뿐이에요.
- 모든 게임의 소리와 그림(3D 학교의 칠판·포스터·책장까지)을 코드로 직접 만들어서, 그림·소리 파일이 하나도 없어요.

```

assets/art.js           호박군, 꼬마 유령, 화살, 사탕 같은 그림

single/jukrim/          죽림고스트 (core.js = 규칙·화살 무늬, game.js = 화면·조작)
multi/escape/           동암초 탈출
  core.js               학교 지도, 탈출 경로, 수수께끼 만들기, 경비원 (Node에서도 돌아가요)
  map.js                대피 안내도 그림 (지도 화면, 복도 포스터)
  tex.js                3D 학교에 입히는 그림 (바닥, 칠판, 포스터, 책장 …)
  world.js              3D 화면, 복도와 경비원
  rooms.js              교실·과학실·도서관·방송실·교무실·보건실·중앙 현관
  game.js               진행, 조작, 수수께끼 판
assets/vendor/three.min.js  3D 그리기 도구 three.js r159 (MIT, 인터넷 없이도 돌아가게 함께 넣었어요)
tests/                  자동 검사
```

## 자동 검사 (개발용)

Node.js 18 이상이 있으면:

```bash
npm test
```

- 호박분투: 6단계를 자동 플레이어가 한 번도 안 떨어지고 끝내는지, 점프마다 난이도별 최소 시간(난이도 2는 0.32초 ~ 난이도 10은 0.16초) 이상 누를 여유가 있는지, 거미줄 구간을 조금 다른 타이밍으로 눌러도 난이도별 기준만큼 건너는지, 단계가 오를수록 실제로 어려워지는지 확인해요.
- 동암초 탈출: 수수께끼 300판을 만들어 늘 풀 수 있는지(교무실 단서는 답이 꼭 하나, 물약은 10mL 눈금으로 딱 나누어짐, 속담 카드에 정답 글자가 다 있음 …), 조심스러운 자동 플레이어가 복도 5곳을 모두 지나가는지(40판 중 95% 넘게, 평균 1분 30초 안) 확인해요.
- 죽림고스트: 화살촉만 맞는지, 빠른 화살이 유령을 뚫고 지나가지 않는지, 모든 화살이 화면 밖에서 들어오는지, 화살 벽에 유령 가까이 구멍이 있는지, 너무 어렵지 않은지(자동 플레이어가 평균 20초 넘게 버티는지) 확인해요.
